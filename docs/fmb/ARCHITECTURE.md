# 字在系統架構

## 系統概觀

「字在」是以靜態檔案為主的前端國語生字學習工具。網頁版由 `index.html` 載入 CSS、JavaScript 與 `data/` 內的 JSON；不需專案後端或安裝前端套件。另可用 `tools/bundle.py` 將頁面、程式碼與教材資料打包成單一 HTML，供離線開啟。

## 模組圖

```text
使用者
  │
  ├── 瀏覽器：網頁版
  │     ├── index.html
  │     ├── src/app.js ─────────── 主畫面、選單、進度、練習、考卷
  │     ├── src/zhuyin.js ──────── 注音與字格繪製
  │     ├── src/readings.js ────── 多音字、讀音覆寫、匯出與條件式回報
  │     ├── src/*.css ──────────── 設計權杖、版面、元件、注音、列印
  │     └── data/*.json ────────── 各年級、學期與版本教材
  │
  ├── 瀏覽器：單檔離線版
  │     └── dist/*.html ────────── 內嵌 CSS、JavaScript 與教材資料
  │
  └── 瀏覽器儲存
        ├── localStorage ───────── 學習進度及讀音覆寫等本機狀態
        └── 使用者匯出 ─────────── 讀音覆寫文字或 JSON

維護與驗證
  ├── tools/build_grades_from_sources.py ── 重建一、三至六年級資料
  ├── tools/build_datasets.py ───────────── 二年級、歷史版及體驗版資料建置
  ├── tools/bundle.py ───────────────────── 產生單檔離線版
  ├── tools/make_sample_pdfs.mjs ────────── 產生範例 PDF
  └── tests/test_zizai.js ───────────────── Node.js 邏輯與資料測試
```

## 主要資料流

### 網頁版載入與使用

1. 瀏覽器載入根目錄 `index.html`，依序載入樣式與 `src/zhuyin.js`、`src/readings.js`、`src/app.js`。
2. `app.js` 根據年級、教材類型與版本選擇對應資料檔；網頁版透過 HTTP `fetch` 讀取 `data/*.json`。
3. 主程式使用教材資料呈現生字進度、互動練習及 A4 測驗卷；`zhuyin.js` 提供注音字格的繪製邏輯。
4. 讀音顯示會參考 `readings.js` 的多音字與使用者覆寫邏輯。使用者的讀音修改儲存在瀏覽器 `localStorage`，不會自動改寫教材 JSON。
5. 進度及偏好等瀏覽器狀態與教材資料分開管理。讀音修改可由使用者匯出；只有使用者主動勾選回報，且執行環境符合程式設定的來源條件，才會嘗試送出回報。

### 教材資料重建

```text
各課生字來源 CSV ─┐
                   ├─ tools/build_grades_from_sources.py ── data/curriculum-115-1-g*.json
教育部辭典資料 ────┘
```

重建一、三至六年級資料需要自行取得來源 CSV 與辭典檔；這些來源檔不隨倉庫提供，且其取得與使用須遵守各自的授權或來源說明。二年級、110 學年度與體驗版資料使用不同的建置腳本及輸入來源，細節見 `README.md` 與 `data/SOURCES.md`。

### 單檔離線版與 PDF

- `tools/bundle.py` 將頁面資源及所需教材資料內嵌到 `dist/index.html` 與 `dist/zi-zai.html`，讓瀏覽器不必以 `fetch` 讀取本機 JSON。打包腳本會檢查資源順序、替換命中數與程式中的網路呼叫限制。
- `tools/make_sample_pdfs.mjs` 使用 Node.js 與本機 Chrome 開啟打包頁面，產生學生版及含答案版 PDF。需要先產生最新單檔，且該腳本會啟動暫時的本機 HTTP 伺服器。

## 外部相依與網路行為

| 項目 | 使用時機 | 說明 |
|---|---|---|
| 瀏覽器與本機 HTTP 伺服器 | 網頁版開發或測試 | 網頁版以 `fetch` 載入本機教材 JSON；不能直接以 `file://` 開啟根目錄頁面。 |
| Google Fonts | 網頁版載入頁面時 | 字型載入失敗時使用系統備援字型；單檔打包版會移除 Google Fonts 資源。 |
| 教育部辭典、筆順與教育百科頁面 | 使用者點選相關連結時 | 由瀏覽器開啟外部頁面；本倉庫不提供這些網站的服務。 |
| `/api/report` | 使用者勾選回報，且執行來源符合程式條件時 | `readings.js` 使用相對路徑送出同源請求。此倉庫是靜態前端專案，未包含該 API 的伺服器端實作；不符合條件或送出失敗時，回報功能會降級，不影響本機讀音修改。 |
| Google 試算表 CSV、辭典來源檔 | 重建特定教材資料時 | 需自行依 `README.md`、`data/SOURCES.md` 取得；來源檔不收入倉庫。 |
| Node.js 內建模組 | 測試及 PDF 工具 | 測試以 Node.js 內建模組執行；PDF 工具另需 Node.js 22 以上及 Chrome。無需安裝 npm 套件。 |

## 架構界線與資料保存

- 專案沒有一般應用程式後端；教材是靜態 JSON，互動邏輯在瀏覽器端執行。
- 教材原始資料、使用者本機狀態與使用者匯出的檔案是不同資料流。讀音修改預設只保存在該瀏覽器的 `localStorage`。
- 網頁版需要 HTTP 伺服器讀取 JSON；單檔離線版將資料內嵌，可直接以 `file://` 開啟。
- 外部服務、來源資料及其授權條件不是本專案可控制的部分。使用或重建資料前，應先閱讀倉庫中的來源與授權說明。
