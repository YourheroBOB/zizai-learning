# 後續修復的驗證計畫

本文件配合 [01-findings.md](01-findings.md)。現況只新增審查紀錄，沒有改程式，因此沒有新的自動化測試被執行。下面是以後改到對應程式時要補的檢查。

## 共通限制

- 測試只用執行器提供的暫存目錄，不讀寫倉庫以外的路徑，不碰使用者家目錄的設定檔。
- 不連線到任何正式服務，不解析真實字型主機，不對正式回報端點送出請求。
- 假的訊息、路徑與憑證欄位只用 `"FAKE_VALUE_FOR_TEST"` 這類明顯假字串。
- 不斷言真實教材的課文、生字清單或使用者讀音備註。
- 既有 `node tests/test_zizai.js` 在只改工具的可靠性時仍應全數通過。依賴未提供來源檔而略過的項目，維持略過，不要把略過改成失敗或通過。

## 依發現對應的檢查

| 發現 | 要證明的結果 | 不該做的事 |
|---|---|---|
| F-01、F-02、F-07 | 假 CDP 不回應或導覽失敗時，父行程在約定逾時內結束；子行程不存在；暫存設定檔已刪；stderr 緩衝有上限；畸形網址回 400 而不是打崩行程 | 啟動本機安裝的 Chrome；對真實除錯埠連線 |
| F-03、F-08 | 驗證失敗或寫入中途例外時，輸出路徑上的原檔位元組不變；三個檔不會只更新一部分 | 寫入倉庫 `data/`；使用真實的二年級來源頁 |
| F-04、F-05 | 缺少年級內嵌資料視為失敗；未選到的年級與 110、體驗版不會在啟動時被剖析 | 用正式 `dist/` 產品做破壞性測試 |
| F-06 | 字型樣式表延遲或失敗時，主要內容仍可繪製 | 對字型服務做長時間壓測 |
| F-09 | 慢回應不會覆蓋較新的年級；逾時會取消；502 最多再試 2 次；400 不重試 | 聽真實埠或讀取倉庫 JSON 以外的網址 |
| F-10 | 成功之後不再 abort；回報呼叫次數是 1；預設不留下含訊息內文的紀錄 | 重試 POST；使用真實備註 |
| F-12 | 空目標的句子函式會返回；大量字格的 SVG 數量符合改法後的預期 | 需要完整瀏覽器才能判斷 `app.js` 是否整頁重繪，該項等原文再補 |
| F-13 | 注入一次寫入失敗後，不留下半套目標檔，舊的完整檔仍可讀 | 覆寫倉庫 `dist/` |
| F-14、F-15 | 紀錄欄位只有事件、年級代號、狀態與耗時；合併後兩個測試用的字都還在 | 印出或快照 localStorage 全文 |

## 人工檢查

程式改到畫面時，在本機靜態伺服器看三件事：年級切換失敗有頁內說明、約 375 像素寬開啟考卷分頁可以捲動與關閉、彈窗遮罩後面的頁面不需要模糊。列印預覽仍是兩頁 A4。這些檢查使用本機檔案即可。

## 完成定義

對應修復的自動化檢查通過，既有 `node tests/test_zizai.js` 的通過與略過數量沒有非預期變化，並且沒有新增對正式網域的請求。PDF 工具與重建腳本的測試預設不呼叫真實 Chrome、不讀取環境變數裡的真實來源路徑。
