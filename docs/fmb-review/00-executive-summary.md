# zizai-learning 程式碼審查摘要

## 1. 審查範圍與方法

- 審查對象：`YourheroBOB/zizai-learning` 預設分支快照，共 37 個檔案。
- 方法：靜態逐檔盤點、資料流程追蹤、錯誤路徑檢查、瀏覽器／建置工具風險分析，以及與既有測試及文件的交叉檢查。
- 本次僅新增 `docs/fmb-review/` 報告，未修改產品程式、資料、測試或設定。
- 本次素材未提供部分大型檔案的完整內容，包括 `src/app.js`、`src/readings.js`、`src/components.css`、`tests/test_zizai.js`、`tools/build_grades_from_sources.py`、`data/GAPS.md`、課程 JSON 及部分歷史測試輸出。對這些檔案只做盤點與風險待辦，不虛構行號；完整內容應再進行第二輪審查。

## 2. 嚴重度定義

| 嚴重度 | 定義 |
|---|---|
| 高 | 可能造成錯誤產品資料、散布權利風險、測試或發布流程阻斷，或 CI 無法可靠結束。 |
| 中 | 可造成局部錯誤、維護風險、資料漂移、可用性或無障礙問題。 |
| 低 | 文件、產物一致性或程式碼可讀性問題，短期不直接影響核心功能。 |

## 3. 整體結論

目前不建議直接將本專案作為新的公開版本散布。建議先完成下列發布阻斷項目：

1. 由 BOB 確認教材來源、辭典衍生資料及程式碼的散布權利。
2. 將教師整理的教材快照明確標示為 `community_compilation`，不可暗示為官方發布。
3. 修正資料 Schema，使其能描述正式、歷史、體驗三種實際資料形狀，並在發布前強制驗證。
4. 修正體驗版空白的注音、部首與筆畫資料。
5. 強化單檔版的「零自動網路請求」保證，涵蓋內嵌 JSON 內的 URL。
6. 為 PDF 產生器加入命令逾時、連線關閉處理及路徑隔離。
7. 以各年級最大題量驗證學生卷固定一頁、答案卷固定一頁。

## 4. 前十大修補建議

| 排名 | 建議 | 對應問題 | 工作量 | 完成定義 |

| 1 | 完成散布權利確認並建立 `LICENSE`、`NOTICE` 與來源台帳 | FMB-001 | 外部法律確認約 2–5 工作天；工程 0.5–1 人日 | 每項資料均有來源、授權、是否可修改與散布狀態；未確認前阻擋公開發布。 |
| 2 | 修正資料 provenance 與 Schema 契約 | FMB-002～004 | 3–5 人日 | 三種資料均可由 Schema 驗證；教師快照不再標成官方；空白欄位與負數筆畫會失敗。 |
| 3 | 重寫二年級／歷史版輸入解析並改為原子寫入 | FMB-006、007 | 3–5 人日 | 不依賴脆弱 regex；失敗不會留下半檔；並行建置有鎖。 |
| 4 | 補齊或明確停用體驗版空白屬性 | FMB-005 | 1–2 人日 | 每個體驗生字均有可用注音、部首、筆畫；資料驗證可阻斷缺值。 |
| 5 | 驗證單檔版所有內嵌資料不會觸發自動網路請求 | FMB-008、009 | 2–3 人日 | 遞迴掃描 JSON URL；瀏覽器測試確認開啟、抽題、列印皆無外部請求。 |

| 10 | 修正發布產物、文件與秘密掃描流程 | FMB-018～021 | 1–2 人日 | `dist/` 生成方式明定；無過期測試輸出混淆；秘密掃描以遮蔽模式執行。 |

### 工作量總結

- 純工程估算：**18–28 人日**，不含需求確認與法律審查。
- 若納入跨瀏覽器、資料來源補齊及法律審查，保守估算為 **3–6 個工程週**。
- 建議先完成排名前 7 項，再進行公開發布；第 8～10 項可納入同一個版本，但不得以「後續再補」取代發布 gate。

## 5. 發布決策原則

本次採以下最保守預設：

- 教師整理的試算表一律視為第三方快照，不視為官方教材。
- 權利未確認時不散布資料衍生物。
- 內嵌資料中的 URL 若可能被自動載入，單檔版必須移除或轉為使用者點擊後才載入。
- 缺少來源快照時，來源重建測試只能標示 skip，不得宣稱完整驗證通過。
- 建置失敗必須保留上一份完整資料，不得產生半寫入檔案。
- 體驗版若無法補齊字形屬性，應在建置時失敗，不應靜默產生空白資料。

## 6. 需要 BOB 決策

1. 教材快照與辭典衍生資料的散布授權處理方式：取得額外授權、改用可散布來源，或由法律審查確認現況。
2. 教師整理試算表的正式 provenance 名稱；本次建議採 `community_compilation`。
3. 體驗版缺資料的處理方式；本次建議補齊，若無法補齊則讓建置失敗，不顯示空白欄位。
4. 公開發布時是否要求來源重建測試必須全數執行；本次建議列為發布 gate，一般開發者可 skip。
