# 字在 FAQ 與疑難排解

本文件整理「字在」使用者與維護者常見問題。若畫面行為與程式不一致，以目前程式為準；教材來源、授權與資料限制請一併參考 [README.md](../../README.md)、[data/SOURCES.md](../../data/SOURCES.md) 與 [data/GAPS.md](../../data/GAPS.md)。

## 使用者常見問題

### 1. 雙擊 `index.html` 後，課程資料沒有載入或頁面功能不完整，怎麼辦？

- **問題：** 直接以 `file://` 開啟網頁版，資料沒有出現。
- **原因：** 網頁版使用 `fetch` 載入 `data/*.json`；瀏覽器通常不允許本機檔案頁面以這種方式讀取資料。
- **解法：** 在 repo 根目錄啟動本機 HTTP 伺服器，再用瀏覽器開啟本機網址：
  ```bash
  python3 -m http.server 8000
  ```
  若埠號已被使用，可改用其他未占用埠號，並開啟相應網址。
- **相關檔案：** `README.md`、`index.html`、`src/app.js`、`data/*.json`

### 2. 啟動伺服器後仍看不到網站，該檢查什麼？

- **問題：** 瀏覽器顯示連線失敗，或打開的不是字在首頁。
- **原因：** 伺服器可能未在 repo 根目錄啟動、埠號不符，或瀏覽器開啟了錯誤路徑。
- **解法：** 確認伺服器工作目錄包含 `index.html`，並在瀏覽器開啟本機伺服器根網址。若使用其他埠號，網址中的埠號也要一致。
- **相關檔案：** `README.md`、`index.html`

### 3. Google Fonts 載入失敗或速度很慢，會影響學習功能嗎？

- **問題：** 網頁字型與預期不同，或載入時等待較久。
- **原因：** 網頁版會向 Google Fonts 載入字型；字型載入依賴外部網路。
- **解法：** 字型載入失敗時會改用系統備援字型，主要功能仍可使用。需要完全離線使用時，可使用單檔離線版。
- **相關檔案：** `README.md`、`index.html`、`src/tokens.css`

### 4. 如何直接離線開啟字在？

- **問題：** 希望不啟動伺服器，或在無網路環境使用。
- **原因：** 根目錄網頁版以 `fetch` 讀取獨立 JSON，不適合直接以 `file://` 開啟。
- **解法：** 先依維護者說明產生單檔離線版，再直接開啟 `dist/index.html` 或 `dist/zi-zai.html`。單檔版將程式與教材資料內嵌，不載入 Google Fonts。產物可能不在初始檔案清單中，需自行產生。
- **相關檔案：** `README.md`、`tools/bundle.py`、`index.html`、`src/app.js`

### 5. 為什麼二年級以外無法選擇 110 學年度或生活情境體驗版？

- **問題：** 切換年級後，歷史版或體驗版不可用或被切回其他教材。
- **原因：** 110 學年度資料與生活情境體驗版僅支援二年級。
- **解法：** 選擇二年級使用這兩種資料集；其他年級請使用 115 學年度資料。
- **相關檔案：** `README.md`、`data/curriculum-110.json`、`data/curriculum-demo.json`、`src/app.js`

### 6. 為什麼年級、版本與學期的課次數不一樣？

- **問題：** 不同選擇下，課次數與生字數有所差異。
- **原因：** 各年級與出版社的教材單元數不同；一年級部分版本另有前導單元。資料只涵蓋目前已收錄的學期與版本。
- **解法：** 確認年級、版本及資料集選擇正確。各版本收錄概況與已知限制見 `GRADES.md`。
- **相關檔案：** `GRADES.md`、`data/curriculum-115-1-g1.json`、`data/curriculum-115-1-g3.json`、`data/curriculum-115-1-g4.json`、`data/curriculum-115-1-g5.json`、`data/curriculum-115-1-g6.json`、`data/curriculum-115-1.json`

### 7. 顯示的目前進度和實際教學進度不同，怎麼調整？

- **問題：** 系統自動預估的課次與班級或家庭進度不一致。
- **原因：** 自動進度是依系統的週次估算，不代表實際授課狀況。
- **解法：** 使用「家長自訂教學進度」選單手動覆寫。若要恢復自動預估，選回自動進度選項。
- **相關檔案：** `index.html`、`src/app.js`、`tests/test_zizai.js`

### 8. 為什麼課次選單中有「數字」、「魔法」或「第 0 課」等名稱？

- **問題：** 部分單元名稱不是一般的「第 N 課」。
- **原因：** 特定來源資料包含正式課次之前的前導單元；前導單元可能以來源標籤呈現，也可能使用 0 或負數的 `lessonNo`。
- **解法：** 依選單顯示的標題選擇單元。這些標題和排序依資料來源及生成規則處理，不代表資料錯誤。
- **相關檔案：** `GRADES.md`、`data/curriculum-115-1-g1.json`、`tools/build_grades_from_sources.py`、`src/app.js`

### 9. 線上練習抽出的題目比所選題數少，怎麼辦？

- **問題：** 實際題數低於選單設定。
- **原因：** 出題會避免重複題目；目前符合所選範圍的題目池可能不足以提供指定數量。
- **解法：** 擴大出題範圍、降低題數，或確認目前課次和「待加強複習」清單是否有足夠生字。
- **相關檔案：** `index.html`、`src/app.js`、`tests/test_zizai.js`

### 10. 精熟、待加強或進度設定重新整理後消失，可能是什麼原因？

- **問題：** 使用者的學習狀態沒有保留。
- **原因：** 進度等狀態存在瀏覽器本機儲存；更換瀏覽器、裝置、網站來源，清除網站資料，或使用瀏覽器的私人瀏覽模式，都可能使狀態無法延續。
- **解法：** 盡量在同一裝置、同一瀏覽器與同一網站來源使用，並避免清除該網站的本機資料。不要把瀏覽器儲存內容公開分享。
- **相關檔案：** `README.md`、`docs/fmb/ARCHITECTURE.md`、`src/app.js`

### 11. 為什麼字卡顯示「破音」或「課本讀音可能不同」？

- **問題：** 生字旁出現讀音提醒。
- **原因：** 讀音資料參考辭典詞頻；有多個常見讀音，或最常見讀音占比未達系統判定門檻時，會標示提醒。辭典詞頻不一定等同特定版本課本的讀音。
- **解法：** 展開字詞詳情查看辭典讀音與占比；如與課本不同，可使用「修改讀音」設定自己的讀音。
- **相關檔案：** `README.md`、`GRADES.md`、`data/GAPS.md`、`data/SOURCES.md`、`src/readings.js`、`src/app.js`

### 12. 修改讀音後，為什麼有些畫面沒有立即更新？

- **問題：** 修改後，練習題、字卡或考卷仍顯示先前的讀音。
- **原因：** 修改會影響使用者瀏覽器中的顯示，但 A4 考卷每次開啟分頁會重新出題；已開啟的考卷可能仍保留舊題目。
- **解法：** 確認修改已儲存，再重新產生考卷或開啟新的考卷分頁。若狀態未保留，請先匯出修改，再檢查瀏覽器本機儲存是否可用。
- **相關檔案：** `README.md`、`DONE_1151001.md`、`src/readings.js`、`src/app.js`

### 13. 自行輸入的讀音無法儲存，原因是什麼？

- **問題：** 修改讀音時出現格式提示或儲存失敗。
- **原因：** 自行輸入欄位只接受注音符號、聲調符號與空白，並會檢查聲調數量與位置及符號順序。
- **解法：** 依欄位提示修正格式，或改選辭典候選讀音。不要輸入備註或其他文字到讀音欄位。
- **相關檔案：** `DONE_1151001.md`、`src/readings.js`、`tests/test_zizai.js`

### 14. 讀音修改存在本機，能否在另一台裝置使用？

- **問題：** 在其他裝置或瀏覽器看不到已修改的讀音。
- **原因：** 修改預設只存於目前瀏覽器的 localStorage，不會自動同步。
- **解法：** 在原裝置匯出文字或 JSON，再由使用者自行保存或交給可信任對象；分享前先檢查備註等內容，避免包含個人或不適合公開的資訊。
- **相關檔案：** `README.md`、`docs/fmb/ARCHITECTURE.md`、`index.html`、`src/readings.js`

### 15. 「回報給維護者」沒有送出或顯示無法回報，是否代表讀音修改遺失？

- **問題：** 回報功能失敗或環境不支援回報。
- **原因：** 回報需要使用者明確勾選，且只在程式允許的來源條件下嘗試送出；靜態 repo 本身沒有 `/api/report` 伺服器實作。網路或外部整合端點故障也會令回報失敗。
- **解法：** 先確認讀音修改仍在本機，再使用匯出功能保存。不要因回報失敗而重複提交包含個人內容的資料；若要回報，先檢查將要分享的內容。
- **相關檔案：** `docs/fmb/ARCHITECTURE.md`、`docs/fmb-runbook/02-configuration.md`、`docs/fmb-runbook/04-troubleshooting.md`、`src/readings.js`

### 16. 查字典或筆順的連結打不開，怎麼辦？

- **問題：** 點擊字典、筆順或教育百科連結後，外部頁面無法載入。
- **原因：** 這些頁面由外部網站提供，不由本 repo 維護；網路、瀏覽器或外部網站狀況可能影響存取。
- **解法：** 確認網路及瀏覽器允許開啟外部連結，稍後再試。外部網站不可用時，字在本身的其他功能仍可繼續使用。
- **相關檔案：** `README.md`、`data/SOURCES.md`、`data/schema.json`

### 17. A4 考卷沒有句子題或出現題數變化，這是錯誤嗎？

- **問題：** 考卷題型或題數與預期不同。
- **原因：** 部分年級資料沒有例句；當沒有句子可用時，系統會隱藏空白句子題區。題數也會受實際可用詞語數量限制。
- **解法：** 確認選擇的年級、版本和課次，並檢查題目池是否足夠。若要重新抽題，使用考卷設定中的重新出題功能。
- **相關檔案：** `README.md`、`data/GAPS.md`、`data/schema.json`、`src/app.js`、`tests/test_zizai.js`

### 18. 列印時控制面板或部分畫面沒有印出，如何處理？

- **問題：** 列印預覽只顯示考卷，或畫面與一般瀏覽器視圖不同。
- **原因：** 列印樣式會隱藏標示為不列印的介面，並將考卷排成 A4 頁面。
- **解法：** 使用「A4 測驗卷」分頁的列印功能，並在瀏覽器列印預覽檢查紙張尺寸與頁數。設定控制項不會列印是預期行為。
- **相關檔案：** `index.html`、`src/print.css`、`src/zhuyin.css`

## 開發與維護常見問題

### 19. 專案需要安裝 npm 套件或後端服務嗎？

- **問題：** 開發者不確定要先安裝哪些相依套件。
- **原因：** 網頁主體是靜態 HTML、CSS、JavaScript 與 JSON，不需要專案後端或前端套件安裝。測試使用 Node.js 內建模組。
- **解法：** 網頁版以本機 HTTP 伺服器供瀏覽器讀取資料；測試依 `README.md` 使用 Node.js 執行。範例 PDF 工具另有 Node.js 與 Chrome 需求。
- **相關檔案：** `README.md`、`docs/fmb/ARCHITECTURE.md`、`tools/make_sample_pdfs.mjs`

### 20. 執行 `node tests/test_zizai.js` 時出現「略過」，代表測試失敗嗎？

- **問題：** 部分測試沒有執行或顯示略過。
- **原因：** 部分測試依賴不隨 repo 提供的辭典來源檔、CSV 快照，或本機開發分支歷史；缺少相應條件時會略過，不等同通過，也不等同失敗。
- **解法：** 先看測試摘要，區分通過、失敗與略過。只在已確認來源授權及取得方式後，才準備外部快照並重跑相關測試。不要把來源檔提交到 repo。
- **相關檔案：** `README.md`、`tests/test_zizai.js`、`tests/RESULT_1151001*.txt`、`data/SOURCES.md`

### 21. 為什麼本機測試結果與 `tests/RESULT_*.txt` 的數字不同？

- **問題：** 測試數量或通過、略過數與存檔結果不一致。
- **原因：** `tests/RESULT_*.txt` 記錄的是不同輪次的歷史輸出；目前執行結果會依來源快照、辭典檔及本機 git 歷史是否存在而異。
- **解法：** 以當前執行的測試輸出為準，並在回報中註明略過原因。不要將歷史輸出當成目前測試結果。
- **相關檔案：** `README.md`、`tests/test_zizai.js`、`tests/RESULT_1151001.txt`、`tests/RESULT_1151001g.txt`

### 22. 如何重建一、三至六年級教材資料？

- **問題：** 需要重新產生對應年級的資料 JSON。
- **原因：** 這些資料由來源 CSV 與辭典檔程式化產生，原始來源檔不隨 repo 提供。
- **解法：** 先閱讀來源與授權說明，依 `README.md` 和 `data/SOURCES.md` 準備所需來源檔，再執行 `python3 tools/build_grades_from_sources.py`。若來源缺少，腳本會說明缺件並結束，不應以猜測內容補資料。
- **相關檔案：** `README.md`、`data/SOURCES.md`、`data/GAPS.md`、`tools/build_grades_from_sources.py`、`data/curriculum-115-1-g1.json`、`data/curriculum-115-1-g3.json`、`data/curriculum-115-1-g4.json`、`data/curriculum-115-1-g5.json`、`data/curriculum-115-1-g6.json`

### 23. 為什麼教材來源 CSV 與辭典原檔不在 repo？

- **問題：** 無法直接從 repo 取得資料重建所需的原始檔。
- **原因：** 來源檔未隨 repo 提供；其中生字清單來源的授權條款未載明，辭典原檔也不收入本倉庫。相關來源目錄已列入 `.gitignore`。
- **解法：** 閱讀 `data/SOURCES.md` 的來源、取得方式及授權說明。使用或散布來源資料前先確認權利與條件；不要將來源快照或原檔加入版控。
- **相關檔案：** `README.md`、`data/SOURCES.md`、`.gitignore`、`tools/build_grades_from_sources.py`

### 24. `tools/build_grades_from_sources.py` 因缺少輸入而結束，接下來該做什麼？

- **問題：** 執行重建腳本時顯示缺少來源檔或結束碼 2。
- **原因：** 腳本需要來源清單所列的 CSV 快照與辭典資料；repo 不包含這些輸入。
- **解法：** 按腳本及來源文件的說明檢查缺少的檔案。若未取得完整輸入，不要以不完整資料重建或覆蓋現有教材檔。
- **相關檔案：** `README.md`、`data/SOURCES.md`、`tools/build_grades_from_sources.py`

### 25. 二年級、110 學年度與體驗版資料可以用同一支腳本重建嗎？

- **問題：** 想用年級資料重建腳本產生所有資料集。
- **原因：** 二年級、歷史版及體驗版使用不同的歷史建置流程與輸入來源。
- **解法：** 一般使用不需要重跑這些資料。若有明確維護需求，先閱讀 `README.md`，確認本機輸入及授權，再研究 `tools/build_datasets.py` 的必要參數。
- **相關檔案：** `README.md`、`tools/build_datasets.py`、`data/curriculum-115-1.json`、`data/curriculum-110.json`、`data/curriculum-demo.json`

### 26. 執行 `tools/bundle.py` 失敗，應先檢查什麼？

- **問題：** 打包時出現替換命中數、資源順序或網路檢查錯誤。
- **原因：** 打包腳本會檢查入口頁面、CSS／JavaScript 順序、替換位置與網路行為；預期內容變更時，斷言可能要求同步更新。
- **解法：** 先確認變更是否刻意調整了資源或程式結構，再檢查腳本指出的斷言及其預期。不要為了讓打包通過而移除網路安全檢查或改動不相關的程式碼。
- **相關檔案：** `tools/bundle.py`、`index.html`、`src/app.js`、`src/readings.js`、`src/zhuyin.js`

### 27. 單檔離線版和網頁版的行為或字型為什麼不同？

- **問題：** 離線版字型或資料載入方式與網頁版不同。
- **原因：** 單檔版將程式與教材資料內嵌，移除 Google Fonts，並使用系統備援字型；網頁版則載入獨立資源。
- **解法：** 驗證網頁版時以本機 HTTP 伺服器開啟根目錄頁面；驗證離線版時使用最新打包產物。兩種版本都應分別確認。
- **相關檔案：** `README.md`、`docs/fmb/ARCHITECTURE.md`、`tools/bundle.py`、`index.html`

### 28. 修改 `data/schema.json` 或教材欄位後，如何判斷是否相容？

- **問題：** 新增或調整資料欄位後，不確定是否會影響前端、建置或測試。
- **原因：** 教材 JSON 會被前端、資料建置腳本與測試共同使用；欄位格式或欄位間關係改變可能造成資料載入或顯示問題。
- **解法：** 先檢查 schema、教材資料結構、前端讀取邏輯及既有測試，再更新對應驗證。不要只因 JSON 可解析就視為資料正確。
- **相關檔案：** `data/schema.json`、`data/curriculum-*.json`、`src/app.js`、`tools/build_grades_from_sources.py`、`tests/test_zizai.js`

### 29. 修改讀音資料後，是否會直接更新所有使用者的課本讀音？

- **問題：** 希望把單一使用者修改同步成正式教材資料。
- **原因：** 使用者修改預設只存在自己的瀏覽器，不會改寫教材 JSON；辭典讀音也不必然等同各版本課本讀音。
- **解法：** 將使用者修改視為個人覆寫，不直接併入教材資料。若要調整正式資料，需另行查核來源、授權與課本依據，並執行完整資料驗證。
- **相關檔案：** `README.md`、`docs/fmb/ARCHITECTURE.md`、`data/SOURCES.md`、`data/GAPS.md`、`src/readings.js`

### 30. 靜態網站上的 `/api/report` 無法使用，應修改哪裡？

- **問題：** 使用者勾選回報後，靜態網站沒有成功接收資料。
- **原因：** repo 只有前端，沒有 `/api/report` 的伺服器端實作；回報端點由外部整合環境提供。
- **解法：** 先確認本機讀音修改與匯出功能仍可用。若需支援回報，應由負責整合端點的維護者檢查服務與相容性；不要在前端加入憑證或把使用者資料送往未確認的端點。
- **相關檔案：** `docs/fmb/ARCHITECTURE.md`、`docs/fmb-runbook/02-configuration.md`、`docs/fmb-runbook/04-troubleshooting.md`、`src/readings.js`

### 31. 範例 PDF 產生失敗，常見原因有哪些？

- **問題：** `tools/make_sample_pdfs.mjs` 無法產生範例 PDF。
- **原因：** 產生流程需要 Node.js 22 以上、Chrome 與已更新的單檔頁面；若找不到 Chrome 或頁面無法完成出題，也會失敗。
- **解法：** 依 `README.md` 先確認必要工具與打包步驟，再檢查腳本錯誤訊息。PDF 不是網站日常使用的必要條件；不需要產生範例時可略過此工具。
- **相關檔案：** `README.md`、`tools/bundle.py`、`tools/make_sample_pdfs.mjs`

### 32. 部署後資源或教材 JSON 讀取失敗，如何定位？

- **問題：** 部署頁面可開啟，但樣式、腳本或課程資料未載入。
- **原因：** 靜態部署可能未包含必要的 `src/` 或 `data/` 檔案，或部署根目錄與相對路徑不一致。
- **解法：** 確認部署內容包含 `index.html`、`src/` 與 `data/`，且頁面從預期的 repo 根目錄提供。用瀏覽器開發者工具檢查本地網站資源請求的狀態；不要在排查時向正式服務送出寫入請求。
- **相關檔案：** `README.md`、`docs/fmb-runbook/01-install-and-deploy.md`、`docs/fmb-runbook/03-health-check.md`、`index.html`、`src/app.js`
