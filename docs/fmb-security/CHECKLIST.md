- [ ] **待驗證** 教材載入或結構驗證失敗時，不應把不完整或未驗證的資料當成有效教材使用。

- [ ] **待驗證** 路徑驗證或權限檢查失敗時，應拒絕請求，而非退回到較寬鬆的檔案讀取行為。
