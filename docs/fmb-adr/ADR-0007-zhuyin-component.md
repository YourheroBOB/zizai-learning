# ADR-0007：注音排版自建元件（TPZhuyin），邏輯與 DOM 分離、可測試、可列印

- 狀態：已採行
- 相關檔案：`src/zhuyin.js`、`src/zhuyin.css`、`src/tokens.css`、`index.html`

## 背景

台灣國小國語作業與考卷的標準格式是「田字格＋右側直排注音」，且：

- 二、三、四聲調號要標在**最後一個注音符號的右上方**；
- 輕聲點要放在**整欄最上方居中**；
- 學生卷必須留白、答案卷要用朱砂紅字；
- 列印成 A4 時字格要固定 14mm 左右，適合鉛筆書寫。

瀏覽器原生 `ruby` 只能做橫排小字，無法滿足直排、田字格與列印需求。

## 決策

1. 自建 `src/zhuyin.js`，掛在 `window.TPZhuyin`，同時以 CommonJS 匯出，讓 Node 測試可直接呼叫（不需瀏覽器）。
2. API 保持小而穩定：`splitSyllable`、`cell`、`word`、`sentence`、`ruby`。狀態用 class 表達：`current`、`upcoming`、`blank`、`answer`、`mastered`。
3. 尺寸以 CSS 變數 `--tpz-size` 控制，提供 `sm` / `md` / `lg` / `xl` / `print`（14mm）級別；元件不自行寫死 px。
4. 顏色走設計權杖（`tokens.css`），元件不硬編色碼；列印媒體查詢負責「學生卷不得洩題」（`blank` 的國字在列印時隱藏）與答案卷紅字。
5. 句子題以「長詞優先」比對目標詞，其餘文字保留為純文字。

## 取捨

**換到**

- 排版規則可被單元測試（純函式拆分音節與調號）、也可被瀏覽器實測。
- 同一套元件同時服務螢幕與列印，格式與課本一致。
- 沒有第三方依賴，符合 ADR-0001。

**付出**

- 版面細節要自己維護（對齊、行高、縮放），每次改動都要同時看螢幕與列印。
- `zhuyin.js` 內同時有 DOM 與非 DOM 兩條路徑，容易出現「Node 可用、瀏覽器壞掉」或反向的落差。

## 後果

- 修改排版後必須檢查：桌面、320/375 寬、列印預覽、答案卷與學生卷兩種狀態。
- Node 端測試不得依賴真實 DOM；若需要在測試中繪製，使用專案既有的假 DOM 做法，不要引入 jsdom 之類的套件（違反 ADR-0001）。
- 列印時隱藏學生卷答案的規則（`.tpz-cell--blank .tpz-cell__char { display:none }`）屬安全相關，不可為了預覽方便而移除。
- 新的題型若要重用注音格，請用 `TPZhuyin.cell` / `word` / `sentence`，不要另行刻一份 HTML。
