# ADR-0004：資料一律由程式從具名來源產生，讀音用辭典詞頻決定

- 狀態：已採行
- 相關檔案：`tools/build_grades_from_sources.py`、`tools/build_datasets.py`、`data/GAPS.md`、`data/SOURCES.md`、`GRADES.md`、`DONE_1151001.md`

## 背景

第一輪以「搜尋後整理」的方式產生三～六年級資料，驗收時發現大量編造：三年級康軒只有 35%、翰林只有 20% 的字出現在來源，六年級部分正確、一年級分課錯。這是本專案最嚴重的一次品質事故（第二輪重做）。

另外，辭典 `dict-revised.json` 的 `heteronyms` **排列順序不代表常用度**（例如「入」第一音是古音、「車」第一音是象棋讀音），早期用手寫覆寫表處理，覆寫表不全導致 146 個字讀音與本課語詞不一致、99 個字聲調錯。

## 決策

1. **生字清單**：只從 CSV 快照的每一列讀取（該列的生字欄），順序照來源，**沒有任何手打生字**；CSV 的每一列都要收錄（含沒有課碼的前導列）。
2. **注音、部首、筆畫**：只從辭典開放資料查詢；查不到的字放入 `FALLBACK_CHARS` 人工補入，並在 `data/GAPS.md` 寫明依據（目前為飢、鷸、据），**不猜測**。
3. **讀音選擇（詞頻法）**：
   - 先掃描辭典中「字數＝音節數」的多字詞條，統計每個字**去聲調**讀音的出現次數，取最高頻者為 base；
   - 再從符合該 base 的 heteronyms 中，用**含聲調**的詞頻取最高的聲調；
   - 輕聲不作主候選，只有在該 base 僅有輕聲時才使用輕聲。
4. **語詞選擇**：只從辭典中含本課生字的二字詞挑選，且要求詞中每個本課生字的音節（含聲調，輕聲除外）等於該字選定讀音；排除同字重複的疊字詞；優先選另一字也是本課生字的詞。
5. **可重現性**：重跑產生器後輸出必須與工作樹逐檔相同（DONE_1151001.md 記載 md5 一致）。
6. **不確定就標記，不改值**：每字輸出 `readings`（辭典全部完整讀音與占比，最多 4 個）與 `ambiguous`（最常見讀音占比 <85%），疑慮清單寫進 `data/GAPS.md`「多音字待人工確認」（目前 143 字）。

## 取捨

**換到**

- 資料可稽核、可重現、與來源逐課比對得起來（測試模組 9、10、11）。
- 不再有「看起來合理但查不到出處」的內容。
- 讀音不再是「辭典第一筆」，而是有統計依據的推論。

**付出**

- 讀音仍是**辭典詞頻的推論，不是課本讀音**；破音字與課本不同是已知限制。
- 資料管線依賴兩份大檔，環境門檻較高。
- 詞頻法對冷僻字、專有名詞可能失準，需要 `GAPS.md` 持續累積人工確認清單。

## 後果

- **嚴禁手改 `data/curriculum-*.json`**：任何資料變更都要改來源快照或產生器後重跑，否則下一次重建就被覆蓋，且與測試的逐課比對不一致。
- 要修正某個字的讀音，順序是：①先確認 `GAPS.md` 是否已列此字與依據；②若是詞頻法邏輯問題，改產生器再重跑並確認其他字沒有連帶變動；③若只是「與課本不同」，走 ADR-0005 的使用者覆寫，**不動資料**。
- 產生器輸出若變動，必須同步檢查：`GRADES.md`（統計表）、`data/GAPS.md`（多音字清單）、測試中的資料合規項目。
- 新增資料欄位時要在產生器一次產生，不接受「先手動補幾筆之後再補程式」。
