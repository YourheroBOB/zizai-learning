# ADR-0009：A4 考卷——螢幕預覽等於列印版面，學生卷與答案卷同一次出題

- 狀態：已採行
- 相關檔案：`src/print.css`、`src/zhuyin.css`、`index.html`（`#page-worksheet`）、`src/app.js`、`tools/make_sample_pdfs.mjs`

## 背景

老師要的是「按下列印就得到兩頁 A4」：第一頁學生試題卷、第二頁解答卷。
常見失敗模式有三個：多印一張空白頁、答案卷洩題到學生卷、以及沒有例句的年級出現整題空白的大題（第六輪實際發生）。

## 決策

1. 以實體單位排版：`@page { size: A4; margin: 0 }`，`.tp-sheet` 固定 `210mm × 297mm`、內距 15/16/14mm，螢幕預覽直接使用同一份 DOM 與同一組 CSS。
2. 答案卷以 `break-before: page` 強制換頁；螢幕上另以間距示意分頁。
3. 列印時隱藏所有介面：`.tp-no-print`、`.zz`（讀音修改相關元件）一律 `display:none`。
4. **主容器內距歸零並提高選擇器權重**：`main.tp-container-main { padding:0; max-width: none; margin: 0 }`。原因是 `index.html` 的內嵌 `<style>` 排在 `print.css` 之後，同權重會被蓋掉，導致整張紙下移約 5.3mm 而多印一頁空白。
5. 沒有例句的年級：**隱藏句子大題**，詞語大題改編號為「一、」；題數上限不超過實際題庫量；卷號依年級與課次產生（例如 `1A-L07`）。
6. 學生卷與答案卷必須來自**同一次出題**；`tools/make_sample_pdfs.mjs` 用同一份 DOM 印兩份 PDF 來證明這件事。
7. 手機預覽以 `transform: scale()` 縮小（600px 以下約 0.48），列印仍是實體 A4。

## 取捨

**換到**

- 所見即所印；兩頁一次完成，老師不必手動分頁。
- 空大題、洩題、多印空白頁這些「老師會立刻發現」的缺陷都有明確對策。

**付出**

- 版面用固定 mm，任何容器內距、邊框、縮放的改動都可能造成溢頁。
- 螢幕預覽需要縮放與負 margin 補償，容易出現「螢幕好看、列印位移」。

## 後果

- 出現多一頁空白時，**第一件事是檢查 `main` 的內距與選擇器權重**，不是改紙張尺寸。
- 新增題型時要同時產生學生卷（`blank`）與答案卷（`answer`）內容，並確認：無空大題、無洩題、題數不超過題庫量、卷號可辨識年級與課次。
- 不要用 px 改 A4 尺寸；不要在列印樣式中依賴 `vh`/`vw`。
- 改動列印樣式後，至少檢查：有例句的年級（二年級）與沒有例句的年級各一份、320/375 寬的螢幕預覽。
- 若同時改到讀音覆寫的顯示，記得覆寫後的讀音要印在兩份卷子上（見 ADR-0005）。
