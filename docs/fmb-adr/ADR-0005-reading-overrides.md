# ADR-0005：讀音疑慮採「標注 + 使用者本機覆寫」，不回寫資料

- 狀態：已採行
- 相關檔案：`src/readings.js`、`src/app.js`、`index.html`（`zz-` 元件與樣式）、`data/GAPS.md`、`DONE_1151001.md`（第七輪）

## 背景

字音以辭典詞頻推定（見 ADR-0004），與各版本課本標注可能不同。維護者無法逐課、逐版本核對全部 2,700 多筆生字；而資料一旦可被使用者直接改寫，就會失去可重建性。

## 決策

1. **標注而不是改正**：每字輸出 `readings`（完整音節含聲調，依詞頻排序並附占比）與 `ambiguous`（最常見讀音占比 <85%）。
   - `ambiguous` 的字在字卡與彈窗標示明顯的「破音」並加註「課本讀音可能不同」。
   - 次要讀音占比 ≥10% 才標一般「破音」（門檻刻意不是「有 2 個以上讀音」，否則 874 筆都要標）；占比 0.00～0.09 的冷僻異讀不標。
2. **使用者覆寫只存在自己的瀏覽器**：
   - localStorage 鍵 `zizai:readingOverrides:v1`，格式為 `{字: {bopomofo, note, ts, grade, publisher, lesson}}`（另有一個輔助欄位記錄修改當下的辭典讀音，用於語詞音節替換判斷）。
   - 可從辭典候選讀音單選、或自行輸入注音；自行輸入只接受注音符號、聲調符號與空白，格式不符不得儲存並說明原因；輕聲點在尾端會正規化為辭典寫法（前置）。
   - 可還原、可匯出純文字與 JSON（下載為本機檔案，不上傳）。
3. **立即套用範圍**：字卡、詳情彈窗、線上練習、A4 學生卷與解答卷（只替換「音節等於該字當時辭典讀音」的位置，避免同字異讀被誤換）。A4 考卷每次開新分頁重新抽題，因此需重新開啟才看到新讀音。
4. **資料不回寫**：覆寫不會改變 `data/*.json`，也不會自動合併進上游資料。
5. **二年級舊資料沒有 `readings` / `ambiguous`**：不標注，但彈窗仍允許自行輸入修改。
6. 讀寫 localStorage 一律 `try/catch`；不可用時提示「重新整理後修改會消失」並引導匯出，不當機。

## 取捨

**換到**

- 資料保持可重建、可稽核；使用者仍有辦法讓畫面符合自己課本。
- 差異可以被收集（匯出或明示勾選回報），成為未來修正的依據。

**付出**

- 修改只存在單一瀏覽器，換裝置或清除資料就消失。
- 「課本讀音是否真的不同」仍需老師對照課本確認，系統不自動判定。
- 多一組需要長期相容的鍵名與資料格式。

## 後果

- **鍵名與格式是相容性契約**：改版必須提供遷移，不能直接換鍵名讓既有覆寫失效。
- 注音格式驗證不可為了方便而放寬；錯誤訊息要具體（字元不合、聲調個數或位置、聲母介音韻母順序）。
- 新增顯示讀音的地方（新題型、新頁面）都必須經過覆寫層，不可直接讀 `characters[].bopomofo`。
- 列印時 `zz-` 相關 UI 一律隱藏，但**覆寫後的讀音要印在學生卷與解答卷上**。
- 回報行為見 ADR-0006：預設不送，勾選才送。
