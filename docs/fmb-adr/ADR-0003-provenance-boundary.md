# ADR-0003：授權不明的原始資料不進倉庫，只提交程式產出的資料檔

- 狀態：已採行
- 相關檔案：`.gitignore`、`data/SOURCES.md`、`GRADES.md`、`README.md`、各 `data/curriculum-115-1-g*.json` 的 `meta.licenseNotes`

## 背景

本專案的資料來自兩個外部來源：

1. 顏國雄老師「115 學年度國小國語各版本生字清單」試算表：站上**沒有 Creative Commons 或其他授權標示**，作者僅聲明筆順資料著作權屬教育部、供教學自學與非商業使用；生字清單原始出處為中研院語言學研究所「生字表字詞資料庫」（本專案未另行查證 115 學年度試算表是否同源）。
2. 教育部《重編國語辭典修訂本》經 g0v 整理的開放資料：**CC BY-ND 3.0 TW**（須署名、不得修改後散布），原檔未收入倉庫。

早期文件曾把來源寫成「公開試算表加某種授權」，查核後確認**沒有出處**，必須改成如實說明（第八輪）。

## 決策

1. **只提交程式產出的資料檔**（生字集合、注音、部首、筆畫、語詞），**不提交原始 CSV 快照與辭典原檔**。
2. `data/sources/gsyan/` 與 `data/sources/moedict/` 列入 `.gitignore`；使用者需自行下載，步驟寫在 `README.md`「如何重建資料」與 `data/SOURCES.md`。
3. 每個資料檔的 `meta.licenseNotes` 與 `README.md`、`data/SOURCES.md`、`GRADES.md` 一律使用如實措辭（「授權條款未載明」「原作者聲明僅供教學自學與非商業性使用」「CC BY-ND 3.0 TW，原檔未收入本倉庫」）。
4. 缺少輸入檔時，重建腳本**印出取得方式後以結束碼 2 離開，不改寫任何資料檔**；測試遇到缺檔標示「略過」，不算失敗也不算通過。
5. 對外部網站的連結（教育部辭典簡編本、筆順學習網、教育百科）只用「使用者點擊才開啟」的方式呈現，不抓取、不內嵌內容。

## 取捨

**換到**

- 不再散布授權狀態不明的原始資料，降低法律風險。
- 資料仍可追溯重建（來源、gid、檔名、取得方式都寫在文件裡）。
- 「缺檔就跳過」讓克隆下來的人不會因為沒有大檔就動彈不得。

**付出**

- 新環境無法一鍵重建，必須先自行下載兩份外部資料。
- 測試項數隨環境變動（單純複製倉庫是 66 項通過、21 項略過；補齊資料後 87 項全過），驗收時容易誤判。
- 文件措辭必須持續維護，一旦有人「順手美化」授權說明就會變成不實陳述。

## 後果

- **提交前檢查**：不得把 `data/sources/**`、CSV、`dict-revised.json(.xz)` 或任何來源快照加進版本控制。
- 文件與程式註解提到授權時，不得寫成「已取得開放授權」或自創授權名稱。
- 倉庫沒有 `LICENSE` 檔，**程式碼授權未指定**；貢獻者與使用者不得自行宣稱授權條款。
- 若要新增第三個資料來源，必須先在 `data/SOURCES.md` 記錄來源、授權、取得方式與是否收入倉庫，再寫程式。
- 不得為了讓測試「全部通過」而把略過改成通過或刪掉比對項。
