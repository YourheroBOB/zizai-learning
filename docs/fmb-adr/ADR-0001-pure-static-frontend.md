# ADR-0001：純靜態前端，無框架、無後端、無建置步驟

- 狀態：已採行
- 相關檔案：`index.html`、`src/*.css`、`src/zhuyin.js`、`src/readings.js`、`src/app.js`、`.nojekyll`、`README.md`

## 背景

使用者是台灣國小的老師與家長。需求是「打開就能用、可以分享連結、可以印考卷」，而且維護者只有少數人。
同時要能放在 GitHub Pages（靜態託管）與既有的 toopower 學習站，不能要求使用者安裝任何東西。

## 決策

1. 只用 HTML、CSS、JavaScript；**不使用任何前端框架、不使用 npm 套件、沒有編譯步驟**。`index.html` 就是可直接發布的入口。
2. 課程資料放在 `data/*.json`，由瀏覽器用 `fetch` 讀取；因此網頁版本機必須用 HTTP 伺服器（`python3 -m http.server`），不能雙擊開檔。
3. 需要「雙擊即可用」的情境另外用 `tools/bundle.py` 產出單檔離線版（見 ADR-0008），而不是引入建置工具鏈。
4. GitHub Pages 以 `.nojekyll` 關閉 Jekyll 處理，直接提供原始檔案。
5. 唯一的網路請求是使用者明示勾選的回報（見 ADR-0006），不是後端 API 依賴。

## 取捨

**換到**

- 零安裝、零維運、零伺服器成本；`git clone` 後一行指令就能跑。
- 老師可以直接把單檔 HTML 傳給家長。
- 沒有套件供應鏈風險，也沒有版本升級造成的破壞。

**付出**

- 沒有型別檢查、沒有模組打包、沒有框架帶來的狀態管理與路由。
- 大型資料（一到六年級全部生字）只能靠「分檔 + 按需載入」控制（見 ADR-0002）。
- 測試與驗證工具必須自己寫（見 ADR-0010）。
- 沒有 SSR／OG 預覽，SEO 與分享卡片較弱。

## 後果

- **任何需要編譯、需要 npm 安裝、或需要伺服器端邏輯的新功能，預設不採用**；若真的必要，必須先新增 ADR 說明例外。
- 程式碼要維持「打開瀏覽器就能除錯」：不得引入只有打包後才能運行的語法。
- 新的外部資源（字型、CDN、API）都必須同時考慮兩個版本：網頁版可用、單檔離線版不可用（打包腳本會把外部資源視為失敗，見 ADR-0008）。
- 資料載入失敗時必須給使用者可行的訊息（重新整理），不得白畫面。
