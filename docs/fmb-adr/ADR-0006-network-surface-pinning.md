# ADR-0006：網路面收斂——預設零請求，回報需明示勾選且同源

- 狀態：已採行
- 相關檔案：`src/readings.js`（回報與白名單）、`src/app.js`（把 `window.fetch` 交給回報模組）、`tools/bundle.py`（網路面斷言）、`README.md`

## 背景

本站使用者是兒童與家長，任何自動上傳都是風險；單檔離線版對外宣稱「不需要網路」。但維護者確實需要知道「哪些字的讀音與課本不同」，因此需要一個**由使用者主動觸發**的回報管道。

## 決策

1. **預設零網路請求**：載入頁面、顯示字卡、出題、列印、匯出，全部不連網。
2. **唯一的請求**：使用者勾選「同時回報給維護者」時，對同源相對路徑 `/api/report` 發 POST。欄位為 app / kind / message / ref / page / viewport / website（`website` 是蜜罐欄位，固定空字串）。
3. **來源白名單**：只在 toopower.cc、www.toopower.cc 與本機開發主機（`http://localhost`、`http://127.0.0.1`）送出；`file://`、GitHub Pages 與其他網域一律不送，只留在瀏覽器。
4. **失敗一律降級**：404、403、429、400、413、5xx、斷線、離線、逾時（10 秒）等情況顯示一行「已存在你的瀏覽器；這個頁面無法送出回報」，不 `alert`、不以 `throw` 中斷流程。
5. **機械可驗證**：`tools/bundle.py` 對內聯後的 JS 做網路面檢查——
   - `fetchImpl(` 呼叫必須恰好 1 處，且路徑常數必須是相對路徑 `/api/report`；
   - 禁用 `XMLHttpRequest`、`sendBeacon`、`WebSocket`、`EventSource`、`importScripts`；
   - 外部網址只允許白名單：三個教育部連結（使用者點擊才開啟）與 SVG 命名空間字串。
6. **測試不連正式服務**：驗證回報行為時用假的 fetch 與明顯假字串（例如 `FAKE_VALUE_FOR_TEST`），不得真的打到 toopower.cc。

## 取捨

**換到**

- 可以對外宣稱「不勾選就不連網」，而且這句話由打包腳本把關，不靠人的自律。
- 回報失敗不會影響學習流程。

**付出**

- 在 GitHub Pages 或離線版發現的讀音問題無法直接回報，只能靠使用者自行匯出再轉交。
- 回報端點（worker）的驗證規則與前端 payload 必須同步維護；`app` 欄位值若不被 worker 接受會回 400，只能在部署端放寬。
- 任何新網路功能都會讓打包失敗，必須顯式修改白名單與本 ADR。

## 後果

- 新增任何網路行為前，必須先改本 ADR 與 `tools/bundle.py`，並在 PR 說明「為何不能離線」。
- 前端不得自行拼接絕對網址或讀取環境變數決定端點；端點必須是同源相對路徑。
- 測試中的憑證、 token、個資一律使用明顯假值，不得使用真實格式前綴。
- 回報的 payload 變更要同時更新測試中「對照 worker 驗證規則」的項目。
