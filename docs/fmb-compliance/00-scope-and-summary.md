# zizai-learning 授權與個資合規盤點

## 目的與範圍

本文件依本次提供的 repo 檔案清單與檔案內容，盤點可辨識的相依項目、授權資訊、個人資料處理流程、保存與刪除方式，以及記錄檔風險，並以台灣《個人資料保護法》（下稱個資法）一般要求列出待補事項。

這是工程盤點，不是法律意見，也不代表已完成正式法律審查。實際責任與義務仍須依營運者、服務部署方式、資料控制者身分及適用法規確認。

## 審查限制

- 提供的檔案清單沒有 `package.json`、npm／Python 鎖定檔或套件清單，未見需安裝的前端套件；README 亦描述本專案不需安裝前端套件。
- 部分關鍵程式內容未提供或僅部分提供，尤其是完整的 `src/app.js`、`src/readings.js`、資料建置腳本及部署端回報 API。因此，本文將文件中描述的行為標為「專案文件記載」，不把它當成已獨立驗證的執行結果。
- 沒有查看 GitHub Pages、toopower.cc、Google Fonts 或其他外部服務的設定、存取紀錄、隱私告知或資料刪除程序。
- 未下載或連線檢查任何外部服務，也未取得外部字型與套件的實際版本及授權檔。

## 摘要判斷

1. **相依套件**：目前可見專案以瀏覽器原生功能、Node.js／Python 標準函式庫為主，沒有可供完整套件授權掃描的套件清單。這不等同於已證明不存在執行環境或外部資源相依。
2. **授權**：教育部《重編國語辭典修訂本》資料記載為 CC BY-ND 3.0 TW；生字清單來源授權未載明，原作者有教學自學、非商業性使用聲明；程式碼授權未指定。這三項都需要分開處理，不能以其中一項授權推定其他內容可自由使用。
3. **個人資料**：專案文件記載，學習進度與讀音覆寫存於瀏覽器 localStorage；讀音修改可含自由文字備註，亦可由使用者選擇送出回報。這些資料在可與學生或家庭識別資訊連結時，可能構成個人資料或個人學習紀錄。
4. **保存與刪除**：本機資料沒有在可見文件中記載自動到期時間或完整清除流程；回報 API 的服務端保存期限、存取權限與刪除程序不在本 repo 可確認範圍。
5. **記錄檔**：工具或平台記錄可能包含請求中繼資料、錯誤資訊與工具輸出。PDF 產生工具文件記載會輸出抽到的第一題句子；它不是已確認的個人資料欄位，但應避免把含個人內容的輸入或輸出帶入日誌。
6. **優先待辦**：確認資料來源與程式碼授權；釐清回報端點的營運者、告知、保存及刪除；補上可理解的個資告知與本機資料清除說明；審核第三方字型與靜態主機的資料流。

## 建議處理順序

- **優先**：BOB 決定是否繼續散布授權不明的生字清單及其衍生資料，以及程式碼授權策略。
- **優先**：由整合站／API 維護者確認回報資料的接收者、用途、保存期限、刪除窗口、存取控管與服務所在地。
- **次優先**：對照完整程式碼實查 localStorage 鍵、清除入口、回報實際 payload、錯誤記錄及網路請求；據此更新本盤點。
- **次優先**：確定字型來源與授權，評估 Google Fonts 請求對使用者告知及資料最小化的影響。
