## 讀音選擇方法（第五輪）

**第五輪讀音完全由程式化辭典詞頻（含聲調）決定：**

1. **統計辭典完整讀音頻率**：對每個字，掃描 dict-revised.json 中全部「字數等於音節數」的
   多字詞條，統計該字各完整讀音（含聲調）出現次數。
2. **取最常見的聲韻母（toneless base）**，然後從與該 base 匹配的 heteronyms 中
   選辭典詞頻最高的完整讀音（含聲調）。
3. **輕聲（˙）不作主讀音候選**：若某字最常見的 base 只有輕聲 heteronym（如 的=˙ㄉㄜ），
   則使用輕聲讀音。
4. **語詞一致性過濾**：語詞選取時強制過濾——詞中每個本課生字的音節，
   聲韻母與聲調都必須與該字選定的讀音相同（輕聲除外）。不一致的語詞直接排除。
5. **避免疊字詞**：語詞選取排除同一字重複兩次的詞。

驗收程式（verify_zizai_readings.py）四節均為 0 個字。

## 多音字標注與使用者修改（第七輪）

- 上表「多音字待人工確認」的 143 字，資料內 `ambiguous: true`，畫面標「破音」並寫「課本讀音可能不同」；`readings` 欄位列出辭典全部完整讀音與占比（最多 4 個）。
- 使用者（家長、老師、孩子）發現和課本不同時，可在詳情彈窗按「修改讀音」，修改只存在自己的瀏覽器（localStorage），立即套用到字卡、線上練習與 A4 測驗卷；可匯出文字或 JSON 轉交老師，也可勾選後回報給維護者。
- 這些修改**不會**自動寫回資料檔；資料的主讀音仍由程式依辭典詞頻決定，是否改資料需老師確認後人工處理。
- 驗收時已發現選不準的字（待老師確認）：「都」（主讀音 ㄉㄨ，課文多讀 ㄉㄡ）、「為」（主讀音 ㄨㄟˊ，「為什麼」讀 ㄨㄟˋ）。這類字最適合用上述回報機制收集課本實際讀音。
- 二年級（`curriculum-115-1.json`）、110 學年度與體驗版資料沒有 `readings`／`ambiguous`，不標注；彈窗仍可自行輸入修改。
