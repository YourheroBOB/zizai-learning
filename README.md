# 字在：國小國語生字學習與測驗系統

「字在」是一個純前端（HTML、CSS、JavaScript，不需要後端與安裝套件）的國小國語生字學習工具，涵蓋 115 學年度上學期一到六年級，康軒、翰林、南一三個版本。

## 功能

- 依週次或課次顯示生字：注音、部首、筆畫、語詞，並可連到教育部辭典與筆順學習網。
- 學習進度小書桌：自動預估本週課次，也可手動指定進度。
- 線上互動答題練習：本週課次、已教累計範圍、加強不熟生字。
- A4 列印：學生考卷與答案卷（直排注音）。
- 多音字標注：辭典讀音不只一種的字會標「破音」，點開可看辭典全部讀音與占比。
- 修改讀音：使用者發現讀音與課本不同時，可以自行改成課本讀音，字卡、練習題與列印考卷都會改用修改後的讀音。
- 年級：一年級至六年級。二年級另有 110 學年度歷史版與生活情境體驗版。

## 使用方式

### 網頁版

倉庫根目錄的 `index.html` 就是網頁版入口，可用 GitHub Pages 直接發布。網頁版會用 `fetch` 讀取 `data/*.json`，所以本機使用時不能直接雙擊開檔，要用 HTTP 伺服器：

```
python3 -m http.server 8000
```

然後用瀏覽器開啟 `http://127.0.0.1:8000/`。網頁版會向 Google Fonts 載入字型；字型載入失敗時會改用系統字型，功能不受影響。

### 單檔離線版

`dist/index.html` 與 `dist/zi-zai.html` 是同一個檔案，把 CSS、JavaScript 與全部年級資料都內嵌在裡面，可以直接雙擊開啟（`file://`），不需要網路與伺服器，也不會載入 Google Fonts。要重新產生這個單檔：

```
python3 tools/bundle.py
```

打包腳本會檢查每一處替換都恰好命中一次，並確認內嵌的 JavaScript 只有一處、且只有使用者勾選才會觸發的網路請求，否則直接報錯結束。

`dist/` 內另有兩份範例 PDF（`sample-worksheet.pdf` 學生版、`sample-worksheet-with-answers.pdf` 含答案版）與幾張說明圖片，是早期版本留下的範例，沒有隨本次更新重新產生。

## 資料限制

- **讀音依辭典詞頻，破音字可能與課本不同。** 每個字的讀音取辭典多字詞條中最常見的讀音，不是逐課對照課本的讀音。
- 標注規則：次要讀音占比達 10% 以上的字標「破音」；最常見讀音占比不足 85% 的字（`ambiguous`）另加註「課本讀音可能不同」。多音字清單與各讀音占比見 `data/GAPS.md`。
- 辭典查無的字（飢、鷸、据）由人工補入，依據記在 `data/GAPS.md`。
- 一年級前段的注音符號教學階段沒有國字，未收錄。
- 三到六年級的語詞沒有釋義與例句，只有二年級有。
- 課名：試算表快照不含課名，課次以「第 N 課」表示。
- 只有 115 學年度上學期，下學期待出版社發行後補入。
- **使用者可用「修改讀音」覆寫讀音。** 修改只存在自己瀏覽器的 localStorage（鍵名 `zizai:readingOverrides:v1`），可匯出成文字或 JSON。在 toopower.cc 版勾選「回報」時，修改才會送給維護者；GitHub Pages 版、單檔離線版與其他網域不會送出任何資料，只能自行匯出。A4 考卷每次開新分頁會重新出題，修改後要開新分頁才會套用到考卷。

## 如何重建資料

一、三到六年級的資料檔 `data/curriculum-115-1-g{1,3,4,5,6}.json` 由程式從來源重建，不是手打：

1. 自行下載顏國雄老師試算表的 15 個分頁，存成 CSV 放進 `data/sources/gsyan/`（這個資料夾已列入 `.gitignore`，不會被提交）。檔名與各分頁的 gid 見 `data/SOURCES.md`；可在瀏覽器開啟各分頁後「檔案 → 下載 → 逗號分隔值 (.csv)」，或用匯出網址，例如南一一年級：`curl -L "https://docs.google.com/spreadsheets/d/10Nq6prSt0s_ZI1Z1phlGEtr0MDDE1wDqEiPmnHWSM_Q/export?format=csv&gid=0" -o data/sources/gsyan/nanyi_1.csv`（其餘分頁換 gid 與檔名）。下載前請先閱讀上一節的授權說明。
2. 自行取得教育部辭典資料：到 <https://github.com/g0v/moedict-data> 下載 `dict-revised.json.xz`，放進 `data/sources/moedict/`（這個資料夾已列入 `.gitignore`，不會被提交）。壓縮檔放著即可，腳本會自動解壓。
3. 執行：

```
python3 tools/build_grades_from_sources.py
```

缺少 CSV 快照（任一個）或辭典檔時，腳本會印出上述取得方式後結束（結束碼 2），不會崩潰，也不會改寫任何資料檔。二年級、110 學年度與體驗版資料的建置腳本是 `tools/build_datasets.py`，它的原始輸入不在本倉庫，需用環境變數 `ZIZAI_G2_HTML`、`ZIZAI_KIMI_JS` 指定檔案路徑；一般情況不需要重跑。

重新產生範例 PDF 需要 Node 22 以上與 Chrome：`node tools/make_sample_pdfs.mjs`（可用環境變數 `CHROME_BIN` 指定 Chrome 路徑）。

## 測試方式

```
node tests/test_zizai.js
```

不需要安裝任何套件（以 Node 22 執行；測試只用 Node 內建模組）。測試涵蓋週次計算、進度覆寫、出題與考卷、各年級資料與試算表快照逐課比對、讀音標注與修改讀音的純邏輯，目前共 87 項。若沒有放教育部辭典檔（見上一節），需要辭典的 4 項會標示「略過」；若沒有放顏國雄老師試算表的 CSV 快照（見上一節），快照逐課比對的 16 項（15 個分頁加 1 項列數檢查）會標示「略過」；若本機沒有開發分支的歷史提交，另 1 項資料比對也會標示「略過」。略過的項目不算通過也不算失敗，其餘照常執行（單純複製本倉庫時是 66 項通過、21 項略過；補齊辭典檔與快照後為 87 項全過）。`tests/RESULT_1151001*.txt` 是各輪實際執行輸出。
